# Cost, Failure Exposure, and Energy-Aware Service Placement

Reproducibility package for the Mid4CC 2026 paper:

**Service Placement for Cost, Failure Exposure, and Energy in the Fog–Edge Continuum**

This repository contains the C++ implementation of the SEQ, MIN, and MAX
greedy service-placement heuristics, the exact branch-and-bound solver,
final experimental results, and scripts used to generate the paper figures.

## Repository Structure

- `src/` — placement algorithms and exact solver
- `results/` — final experimental CSV files
- `results/summaries/` — processed result summaries
- `scripts/` — figure-generation scripts
- `figures/` — figures reported in the paper
- `Makefile` — compilation configuration

Detailed reproduction instructions will be added with the final paper release.
